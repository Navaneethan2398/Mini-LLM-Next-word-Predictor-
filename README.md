# Mini-LLM-Next-word-Predictor-
A beginner-friendly Mini LLM project built using PyTorch that predicts the next word based on the current word.

This project demonstrates the core fundamentals behind Large Language Models (LLMs) such as:

- Tokenization
- Vocabulary Creation
- Word Embeddings
- Neural Networks
- Softmax Prediction
- Training Loop
- Next Word Prediction

---

# Project Workflow

Text
→ Tokenization
→ Word IDs
→ Embeddings
→ Linear Layer
→ Softmax
→ Next Word Prediction
